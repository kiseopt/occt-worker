# 内存上限真机测试

1. 通过 HTTP 服务打开 `tests/device/`，填写设备型号、系统版本和浏览器。
2. 从最大的候选值开始，选择 `preview` 或 `full`，再点“开始二分测试”。
3. 典型负载完成后，页面会继续增长并写满 wasm 线性内存。若页面显示“已捕获 RangeError”，复制二分结果；若出现白屏或页面重载，重新打开页面并记录“上次尝试未完成”，然后改测小一档。
4. 继续测试，直到找到在该设备、系统版本和测试负载下，典型负载能完成且超限时抛出 `RangeError` 的候选值。

结果只代表填写的设备、系统版本和测试负载，不能作为 iPad 的通用内存上限。
